# Kanon mark

The K is Kanon's icon. Its upright is a measuring rod with gold ticks (κανών means "measuring rod, rule"); its lower leg is the site's gold creek line, ending in a ripple.

| File | Use |
|---|---|
| `kanon-mark.svg` | Master mark; 48 px and up |
| `favicon.svg` | Simplified mark for 16–32 px (no ticks) |
| `favicon.ico` | 16, 32, 48 px for older browsers |
| `apple-touch-icon.png` | 180 px iOS home screen |
| `icon-192.png`, `icon-512.png` | Web app manifest / install icons |

Colors: sea `#072634`, ink `#f2f8f9`, rope `#d9b382`. The mark is drawn as plain shapes, not set in a font, so it carries no font license.

Not yet wired into `index.html`; the page still uses its inline creek favicon until the site update.
